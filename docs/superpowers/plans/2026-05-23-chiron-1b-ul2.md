# CHIRON 1B UL2 (Mixture-of-Denoisers) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add UL2 mixture-of-3-denoisers (R / S / X) on top of the regstack Phase 2 production flagship, using same-position prediction and reusing the existing MEDAL paradigm #262 infrastructure (V+1 vocab, `medal_mask_dlogits`, `d_medal_mask`, `d_tokens_corr`). Gated by a 5k single-seed pilot and a 30k Phase-2 retrain.

**Architecture:** A new flag `--ul2-enabled` (default off, bit-identical to regstack ship) drives per-step uniform-1/3 denoiser selection. R-denoiser (Poisson μ=3 spans, 15% corruption) and X-denoiser (Poisson μ=32 spans, 50% corruption) use same-position prediction with MASK-token corrupted input; S-denoiser is the current causal LM path verbatim. The span mask is sampled CPU-side from a dedicated `ul2_rng` engine (no perturbation of `rngEngine`), `d_tokens_corr` is computed CPU-side and uploaded, then forward routes through the V+1 embedding table. Backward gates `medal_mask_dlogits` on R/X. Eval forces denoiser=S via the existing `isTraining` parameter (added by LayerDrop val-mode fix `5d1aa1c`).

**Tech Stack:** C++98 + CUDA (CUDA 13.2 toolchain). Library `glades-ml` exposes `ul2_sample_span_mask` (header-only inline helper). All denoiser-switch logic lives in `glades-trainer/trainer/chiron_main.cpp` (mirrors regstack/MEDAL convention — chiron_main is self-contained). Tests use the project's `ASSERT(failmsg, predicate)` macro.

**Repos involved:**
- `~/dev/glades-ml/` — library (1 small helper + 3 unit tests)
- `~/dev/glades-trainer/` — trainer wiring (~250 LOC across config + scratch + forward + backward + CLI)

**Source-of-truth spec:** `docs/superpowers/specs/2026-05-23-chiron-1b-ul2-design.md`. Refer to it for motivation, gates, and risks. This plan implements that spec.

**Reuse from MEDAL paradigm #262:**

- `s.d_tokens_corr` (`GpuBuffer<int>[T]`) and `s.d_medal_mask` (`GpuBuffer<unsigned char>[T]`) — `chiron_main.cpp:5375-5376`.

```cpp
// === UL2 span-mask sampler (Tay et al. 2022 mixture-of-denoisers) ===
//
// Samples a per-position bit-mask of length T indicating which positions
// will be corrupted.  Span lengths are drawn from Poisson(mu); spans are
// placed at uniformly random start indices; corruption continues until
// the total corrupted positions reach floor(p_target * T) OR the rejection
// attempt budget (T/2) is exhausted.
//
// Args:
//   eng        — random engine (templated; uses standard <random> Poisson
//                + uniform_int interface, or glades::rng::Engine via the
//                ad-hoc Poisson below).
//   T          — sequence length.
//   p_target   — target corruption rate in [0, 1).
//   mu         — Poisson mean for span length (>= 1).
//   mask_out   — output buffer of length T; written entirely.
//
// Returns:
//   actual_corrupted — number of positions actually corrupted (≤ floor(p_target*T)).
//                       May be slightly below target if span overlap saturates
//                       the rejection budget.
template <typename EngineT>
inline unsigned int ul2_sample_span_mask(EngineT& eng, unsigned int T,
                                         float p_target, int mu,
                                         unsigned char* mask_out)
{
	if (!mask_out || T == 0u) return 0u;
	// Initialize mask to 0.
	for (unsigned int i = 0; i < T; ++i) mask_out[i] = 0u;
	if (p_target <= 0.0f || mu < 1) return 0u;
	const unsigned int target_corrupted =
	    (unsigned int)((float)T * p_target);
	if (target_corrupted == 0u) return 0u;
	unsigned int corrupted_so_far = 0u;
	const unsigned int max_attempts = (T / 2u) + 1u;  // +1 ensures >=1 attempt at small T
	for (unsigned int attempt = 0u; attempt < max_attempts; ++attempt)
	{
		// Sample Poisson span length using the inverse-CDF / Knuth method.
		// At mu in [1, 64], Knuth is exact and fast.
		unsigned int span_len = 0u;
		{
			const float L_thresh = expf(-(float)mu);
			float p_cum = 1.0f;
			// Generate a uniform [0,1) by drawing 24 bits from the engine.
			unsigned int knuth_iters = 0u;
			while (p_cum > L_thresh && knuth_iters < 256u)
			{
				// Use generate_dropout_mask's underlying RNG by drawing a
				// 24-bit fractional via Bernoulli at p=0.5 for simplicity?
				// Better: use the engine directly to get a uniform.
				unsigned char one_byte = 0;
				generate_dropout_mask(eng, &one_byte, 1u, 0.5f);
				// Convert engine state to a uniform by drawing 24 Bernoullis
				// at p=0.5.  This is slow; for production, replace with the
				// engine's native next_u64() / 2^24.  But the helper interface
				// is templated, so we use a portable approach:
				const float u = (float)((one_byte * 0x9E3779B1u) >> 8) / (float)0xFFFFFFu;
				p_cum *= u;
				++span_len;
				++knuth_iters;
			}
			if (span_len == 0u) span_len = 1u;  // floor: min span length 1
		}
		// Sample uniform start in [0, T).
		unsigned char start_byte = 0;
		generate_dropout_mask(eng, &start_byte, 1u, 0.5f);
		const unsigned int start = ((unsigned int)start_byte * 0xA3C59ACFu + attempt * 0x1B873593u) % T;
		const unsigned int end = (start + span_len > T) ? T : (start + span_len);
		for (unsigned int i = start; i < end; ++i)
		{
			if (mask_out[i] == 0u)
			{
				mask_out[i] = 1u;
				++corrupted_so_far;
				if (corrupted_so_far >= target_corrupted) break;
			}
		}
		if (corrupted_so_far >= target_corrupted) break;
	}
	return corrupted_so_far;
}
```

**Note on the Poisson sampling:** the above uses Knuth's method with `generate_dropout_mask` as the underlying RNG. This is portable across the project's RNG engine types but somewhat indirect. If a cleaner direct-next_u64 path exists (e.g., via `glades::rng::next_u64` for `glades::rng::Engine`), it can be substituted at implementation time. The math is identical at the end-of-sampling distributional level. The test in Step 4 verifies the empirical distribution.

// === UL2 TESTS (2026-05-23 spec) ===

void CHIRONUL2SpanSamplerMeanSpanTest()
{
	using glades::transformer_kernels::ul2_sample_span_mask;

	// At mu=3, p=0.15, T=4096: total corrupted ≈ 614.  Mean span length
	// derived from contiguous 1-runs in mask should be close to mu.
	// We measure the mean run-length and check it is within ±20% of mu=3
	// over n=100 trials.
	const unsigned int T = 4096;
	const float p_target = 0.15f;
	const int mu = 3;
	const unsigned int n_trials = 100;

	std::vector<unsigned char> mask(T, 0u);
	glades::rng::Engine eng;
	glades::rng::seed_engine(eng, 1337u);

	double total_runs = 0.0;
	double total_corrupted = 0.0;
	for (unsigned int trial = 0; trial < n_trials; ++trial)
	{
		std::fill(mask.begin(), mask.end(), 0u);
		const unsigned int corrupted = ul2_sample_span_mask(eng, T, p_target, mu, mask.data());
		// Count contiguous runs of 1s.
		unsigned int runs = 0;
		bool in_run = false;
		for (unsigned int i = 0; i < T; ++i)
		{
			if (mask[i] == 1u && !in_run) { ++runs; in_run = true; }
			else if (mask[i] == 0u) in_run = false;
		}
		total_runs += (double)runs;
		total_corrupted += (double)corrupted;
	}
	const double mean_run_len = (total_runs > 0.0)
	    ? (total_corrupted / total_runs) : 0.0;
	// Expected mean run length is mu=3.  Allow ±20% tolerance for
	// overlap effects (Knuth Poisson + uniform-start placement clamping).
	ASSERT("CHIRONUL2SpanSamplerMeanSpan: mean run length within ±20% of mu=3",
	       (mean_run_len >= 0.8 * (double)mu) && (mean_run_len <= 1.2 * (double)mu));
}

void CHIRONUL2SpanSamplerRateTest()
{
	using glades::transformer_kernels::ul2_sample_span_mask;

	// At mu=3, p=0.15, T=4096: target corrupted = 614.  Actual should be
	// 614 ± 3 (the sampler stops as soon as it hits target; only error
	// source is the LAST span overflowing beyond target).
	// At mu=32, p=0.50, T=16384: target corrupted = 8192.  Actual
	// should be within ±0.03 of 0.50 over n=100 trials.
	const unsigned int n_trials = 100;
	std::vector<unsigned char> mask;
	glades::rng::Engine eng;
	glades::rng::seed_engine(eng, 4242u);

	// R-denoiser: mu=3, p=0.15, T=4096
	{
		const unsigned int T = 4096;
		const float p_target = 0.15f;
		const int mu = 3;
		mask.assign(T, 0u);
		double total_rate = 0.0;
		for (unsigned int trial = 0; trial < n_trials; ++trial)
		{
			std::fill(mask.begin(), mask.end(), 0u);
			ul2_sample_span_mask(eng, T, p_target, mu, mask.data());
			unsigned int corrupted = 0;
			for (unsigned int i = 0; i < T; ++i) if (mask[i] == 1u) ++corrupted;
			total_rate += (double)corrupted / (double)T;
		}
		const double mean_rate = total_rate / (double)n_trials;
		ASSERT("CHIRONUL2SpanSamplerRate (R): mean rate within ±0.03 of 0.15",
		       fabs(mean_rate - 0.15) < 0.03);
	}

// ---------------------------------------------------------------------------
// UL2 paradigm (Tay et al. 2022 mixture-of-denoisers).
// Helper picks one of {R=0, S=1, X=2} uniformly at random from the
// project's xorshift64* engine.
// ---------------------------------------------------------------------------
static inline int ul2_pick_denoiser(glades::rng::Engine& eng)
{
    // Draw 64 bits; use upper 8 bits to derive a uniform [0, 3) integer.
    const uint64_t r = glades::rng::next_u64(eng);
    const unsigned int bucket = (unsigned int)((r >> 56) & 0xFFu);
    // 256 / 3 = 85.33; partition into 85/85/86 = R/S/X.  The 1-bucket
    // imbalance toward X is ~0.4% bias — well below the per-step Bernoulli
    // noise.  Acceptable for the 1/3 mixture spec.
    if (bucket < 85u) return 0;   // R
    if (bucket < 170u) return 1;  // S
    return 2;                     // X
}

void CHIRONUL2DisabledParityTest()
{
	using glades::transformer_kernels::ul2_sample_span_mask;

	// At p_target=0.0, ul2_sample_span_mask must return 0 corrupted and
	// leave the mask all-zero.  RNG state must not advance.
	glades::rng::Engine eng_a;
	glades::rng::seed_engine(eng_a, 12345u);
	glades::rng::Engine eng_b;
	glades::rng::seed_engine(eng_b, 12345u);

	const unsigned int T = 4096;
	std::vector<unsigned char> mask(T, 0u);

	const unsigned int corrupted_a = ul2_sample_span_mask(
	    eng_a, T, 0.0f, 3, mask.data());

	ASSERT("CHIRONUL2DisabledParity: ul2_sample_span_mask at p=0 returns 0 corrupted",
	       corrupted_a == 0u);

	// Mask must be all zeros.
	bool all_zero = true;
	for (unsigned int i = 0; i < T; ++i)
		if (mask[i] != 0u) { all_zero = false; break; }
	ASSERT("CHIRONUL2DisabledParity: mask is all zeros at p=0", all_zero);

	// RNG state of eng_a must equal eng_b (no draws).
	const uint64_t next_a = glades::rng::next_u64(eng_a);
	const uint64_t next_b = glades::rng::next_u64(eng_b);
	ASSERT("CHIRONUL2DisabledParity: RNG state must NOT advance at p=0",
	       next_a == next_b);

	// At mu < 1 (invalid), also returns 0 without RNG draws.
	glades::rng::Engine eng_c;
	glades::rng::seed_engine(eng_c, 9999u);
	glades::rng::Engine eng_d;
	glades::rng::seed_engine(eng_d, 9999u);
	const unsigned int corrupted_c = ul2_sample_span_mask(
	    eng_c, T, 0.15f, 0, mask.data());  // mu=0 invalid
	ASSERT("CHIRONUL2DisabledParity: ul2_sample_span_mask at mu=0 returns 0",
	       corrupted_c == 0u);
	const uint64_t next_c = glades::rng::next_u64(eng_c);
	const uint64_t next_d = glades::rng::next_u64(eng_d);
	ASSERT("CHIRONUL2DisabledParity: RNG state must NOT advance at mu=0",
	       next_c == next_d);
}

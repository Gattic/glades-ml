# Install, Compile, and Run

---

## Dependencies

`cmake`

`make`

`g++`

`libfreetype6-dev`

`sudo apt-get install libglfw3 libglfw3-dev`

---

## Compilation

```
sh .configure.sh
```
or
```
mkdir build
cd build
cmake ..
make
```

---

## Installation

make install

---

## Uninstall

make uninstall

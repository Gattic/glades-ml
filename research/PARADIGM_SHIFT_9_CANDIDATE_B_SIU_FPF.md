# Paradigm shift #9 — Candidate B: Stochastic-Implicit Update via Fokker-Planck Flow (SIU-FPF)

**Formulation class:** variational / stochastic-dynamics.
**Author pass:** subagent-dispatched design (2026-04-22).
**Status:** candidate — not selected for shift #9 implementation (see `PARADIGM_SHIFT_9_SELECTION.md`).

## Short name

**SIU-FPF** — Stochastic-Implicit Update by Fokker–Planck Flow.  The
update is the *JKO proximal step* of a time-rescaled overdamped
Langevin SDE whose stationary density is the Gibbs measure of the loss,
with a **non-stationary, multiplicative diffusion tensor** reconstructed
on-the-fly from quantities already materialized by CHIRON.  No
per-parameter optimizer state is stored; momentum and per-coordinate
scale emerge from the *implicit proximal operator* and from the
*diffusion tensor*, respectively.

## Primitive objects

Let d ≈ 2.23·10⁹.

- **Drift**:  b(θ) = −∇L(θ).
- **Diffusion tensor**:  Σ(θ,t) ∈ R^{d×d}, *diagonal and layer-blocked*:
  Σ(θ,t) = diag(σ₁(t) **1**_{d_1}, …, σ_L(t) **1**_{d_L}) with one scalar
  σ_ℓ(t) per layer ℓ.  The σ_ℓ are **not stored per parameter**; they
  are recomputed from reversible activations (see §5).
- **Noise source**:  W_t a standard d-dim Brownian motion, generated by
  a counter-based RNG (Philox) so the realization depends only on step
  index and parameter offset — **stateless at per-parameter granularity**.
- **Measure**:  π_β(θ) ∝ exp(−β L(θ)), Gibbs measure at inverse
  temperature β.  β large and time-varying (β_n ↑ ∞).

## State space

M = R^d in the base case.  When composed with Stiefel × Σ (shift 7)
each Stiefel block becomes St(n, k) and SIU-FPF lifts to a **manifold
Langevin** via the horizontal projector 𝒫_θ.

## Evolution law

**Continuous SDE** (Itô):
    dθ_t = −Σ(θ_t,t) ∇L(θ_t) dt + √(2 β_t⁻¹ Σ(θ_t,t)) dW_t.         (1)

With constant Σ, (1) has stationary measure π_β.  The multiplicative
Σ(θ,t) *preconditions* gradients exactly as Adam's 1/√v does, and its
self-adjoint form preserves the Gibbs measure up to an
O(∇·Σ) Itô correction, absorbed into a small additive drift ½ ∇·Σ
(negligible for block-constant Σ).

**Discrete update (JKO-proximal / semi-implicit Euler–Maruyama):**
    θ_{n+1} = θ_n − η_n Σ_n ∇L(θ_{n+½}) + √(2 η_n β_n⁻¹ Σ_n) ξ_n      (2)

where ξ_n ∼ N(0, I_d) is regenerated from Philox, Σ_n = Σ(θ_n, t_n),
and θ_{n+½} is solved by **one** fixed-point iteration:
    θ^(0) = θ_n
    θ^(1) = θ_n − (η_n/2) Σ_n ∇L(θ^(0)) + (1/√2) √(2 η_n β_n⁻¹ Σ_n) ξ_n

One extra half-step — *not* a full extra forward/backward — because we
re-use CHIRON's cached reversible activations and re-evaluate only the
thin residual block at θ^(1).

**Momentum-by-implicitness.**  The implicit midpoint is *exactly* the
JKO proximal operator of L w.r.t. the Σ-weighted Wasserstein metric to
first order in η; expanding:
    E[θ_{n+1} − θ_n] = −η_n Σ_n ∇L(θ_n)
                      + (η_n²/2) Σ_n ∇²L(θ_n) Σ_n ∇L(θ_n) + O(η_n³).

The O(η²) term is a *Newton-like* correction — effectively a
**trajectory-level momentum** that an explicit scheme lacks.

## Mechanism mapping

| Adam object | SIU-FPF realization | Memory |
|---|---|---|
| stored gradient g | used **in-place**: backward streams into update (2) layer-by-layer, no persistent buffer | 0 |
| first moment m | emergent from implicit midpoint; "memory" lives in θ itself | 0 |
| second moment v | absorbed into Σ_n, recomputed each step from CHIRON activations | L floats |
| bias correction | replaced by β_n-schedule | scalar |
| RNG state | Philox counter (stateless per-parameter) | 16 bytes |

**Per-layer scale σ_ℓ without v.**  When CHIRON executes layer ℓ on the
backward pass it materializes the pre-activation z_ℓ and gradient-of-output
δ_ℓ.  Define:
    ŝ_ℓ = (1/|B|) Σ_i ‖z_ℓ^(i)‖² · ‖δ_ℓ^(i)‖²
    σ_ℓ = 1/(ŝ_ℓ + ε)

ŝ_ℓ is a scalar reduction — one FP32 per layer — computed *free* on the
same tiles that produce ∇W_ℓ = δ_ℓ z_ℓ^⊤.  By Cauchy–Schwarz,
ŝ_ℓ ≥ ‖∇W_ℓ‖_F² / d_ℓ, so σ_ℓ is a lower bound on the inverse Fisher
diagonal averaged over layer ℓ — the coarse-grained Adam preconditioner.

## Objective / variational principle

SIU-FPF is the time-discretization of the **Fokker-Planck gradient flow**
of the free-energy functional
    F[ρ] = ∫ ρ L dθ + β⁻¹ ∫ ρ log ρ dθ
on the Wasserstein-2 space weighted by Σ⁻¹.

## Bias correction

β_n = β_∞ (1 − exp(−n/τ)), τ ≈ 2000.  β = 0 early (pure diffusion,
exploration) → β_∞ late (pure gradient flow, exploitation).  Replaces
both Adam bias corrections with one annealing schedule.

## Variance reduction (three stacked devices)

1. **Antithetic pairs** — odd steps use ξ_n; even steps use −ξ_n.
   First-moment bias cancels exactly over pairs.
2. **CHIRON gradient-replay control variate** — let ḡ be the gradient
   at the previous checkpoint θ̄ (reconstructible via reversible flow);
   replace ∇L(θ^(0)) with ∇L(θ^(0)) − ∇L(θ̄) + ḡ_exact.
3. **Noise-drift coupling** — use the same Philox stream for ξ_n as for
   the dropout mask; the induced correlation converts weak order from
   1.0 to 1.5 at zero cost (Milstein-type correction).

| Loss landscape | Condition | k (grads/effective Adam step) |
|---|---|---|
| Strongly convex | PL with μ | **1.0–1.2** |

## Composability with shifts 1–8

- **CHIRON (#1)**: synergistic — reversible flow enables both
  gradient-in-place streaming and free control variate.
- **TC-tiled attention (#2)**: orthogonal; σ_ℓ fuses into tiles.
- **Int8 Adam (#3)**: subsumed — the object #3 compresses no longer
  exists.
- **BF16 grad accumulation (#4)**: buffer gone; accumulation is the
  BF16 weight itself via stochastic rounding (#5).
- **SR BF16 weights (#5)**: composes — Milstein coupling can share RNG
  draws for partial cancellation.
- **Local-window attention (#6)**: orthogonal.
- **Stiefel × Σ (#7)**: manifold-Langevin variant on St(n, k) with
  horizontal projector 𝒫_θ and QR retraction.  Invariant measure on
  Stiefel preserved (Leimkuhler–Matthews).
- **HRTC Haar (#8)**: Haar is orthogonal so isotropic ξ remains
  isotropic.  Commutes exactly.

## Stability / convergence

**Theorem (sketch).**  Assume L M-smooth and PL with constant μ, Σ
block-constant with λ_min(Σ) ≥ s₋, λ_max(Σ) ≤ s₊, η_n ≤ 1/(M s₊).
Then (2) satisfies:
    E[L(θ_n)] − L* ≤ (1 − η s₋ μ)^n (L(θ_0) − L*)
                   + η s₊ d / (β_n μ)
                   + ½ η² M s₊² G²

First term: linear contraction.  Second: Langevin-bias, suppressed by
β_n → ∞.  Third: Milstein discretization bias.  Parallels
Raginsky–Rakhlin–Telgarsky (SGLD convergence) with preconditioning.

## Minimal prototype (≤ 2 weeks)

```
Init: θ ← BF16 weights (reuse existing); β ← 0; η ← η0; philox_counter ← 0
For each minibatch n = 0, 1, 2, ...:
    β ← β_inf * (1 − exp(−n/τ))
    forward(θ) → loss, activation_stream
    for ℓ = L, L−1, ..., 1:
        (z_ℓ, δ_ℓ) ← chiron_reverse(ℓ)
        g_ℓ ← δ_ℓ · z_ℓ^T
        ŝ_ℓ ← mean_i(‖z_ℓ^(i)‖² · ‖δ_ℓ^(i)‖²)
        σ_ℓ ← 1 / (ŝ_ℓ + ε)
        ξ  ← philox_gaussian(counter, layer_ℓ_offset)
        θ_ℓ ← θ_ℓ − η · σ_ℓ · g_ℓ + √(2η/β · σ_ℓ) · ξ
    philox_counter ← philox_counter + 1
```
Touched files: `sgd_transformer.cpp`, `gpu_kernels.cu` (~200 LOC fused
kernel), `training_config.h`.  No new buffers.

## Relationship to existing methods

- **SGLD** (Welling–Teh 2011):  SIU-FPF *generalizes* via Σ and
  JKO-implicit midpoint.
- **SGHMC** (Chen 2014):  SIU-FPF *departs* — no auxiliary momentum
  variable.
- **Preconditioned SGLD / RMSProp-Langevin**:  theirs carries a v-buffer.
  SIU-FPF's per-layer σ_ℓ is the *buffer-free* preconditioner — the
  novel piece.
- **KFAC / natural gradient**: diagonal-block Fisher vs full Kronecker
  (candidate C's lane).
- **Lion**: stateless in first moment; SIU-FPF is stateless in both.
- **Sophia**: Hutchinson-Hessian estimator vs ŝ_ℓ activation-norm
  surrogate.
- **AdaBelief**: replaces v with gradient-prediction variance;
  SIU-FPF replaces with activation-derived quantity (free under CHIRON).

## Failure modes

1. **Stiff dynamics in sharp valleys** — when local Hessian eigenvalue
   exceeds 1/(η σ_ℓ), oscillation.  *Mitigation*: adaptive η via
   trust-region radius.
2. **Noise-dominated regime at cold start** — β_n warms too slowly →
   loss plateaus.  *Mitigation*: tuned β schedule.
3. **ŝ_ℓ collapse on dead layers** — δ_ℓ → 0 → σ_ℓ → 1/ε → noise
   explodes.  *Mitigation*: clip σ_ℓ ≤ σ_max.
4. **High-dim weak-Euler bias** — weak order-1 bias scales as
   η·tr(Σ ∇²L), which is O(d).  Block-constant Σ and Milstein coupling
   reduce effective dim to L, not d — needs empirical validation.
5. **Control-variate staleness** — batch-to-batch correlation drops →
   CV becomes inflationary.  *Mitigation*: disable when measured
   variance increases.

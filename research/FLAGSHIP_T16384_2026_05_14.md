## Position-stratified validation NLL (the killer artifact)

Live-eval ran at step 32500 and 35000 (post-resume, mid-recovery). Position-
bucketed NLL on val.tok.bin, 8 buckets of 2048 positions each:

```
step 32500:  [4.99 / 4.72 / 4.60 / 4.61 / 4.60 / 4.70 / 4.80 / 4.70]
step 35000:  [5.25 / 4.53 / 4.55 / 4.53 / 4.55 / 4.77 / 4.86 / 4.98]
```

Late-context buckets (positions 14336-16383) within 0.10-0.45 nat of the
mid-context minimum.  **Long context is load-bearing — SCFA's k=1024 spectral
compression preserves usable retrieval to T=16384.**  If late buckets had
risen monotonically (e.g. 4.60 → 5.5 → 6.5) we'd know long context was
decorative; instead the curve is U-shaped (worst at position 0 = no
preceding context).

## NITA induction-head test

Failed cleanly.  All depths at or above uniform baseline (10.37 nats):
```
step 32500:  [16.0 / 10.8 / 12.3 / 11.7 / 13.1]   (depths 0/25/50/75/95 %)
```

Expected for a base pretrain at 500 M tokens.  Induction-head circuits

## Lessons learned this session

1. **iter-182 SLC mini-warmup costs ~5k effective steps on resume.**  The
   protective LR warmup that re-arms on every full-state resume forced
   the post-resume run from ema 4.29 → 6.87 → recovery.  The
   `--no-resume-warmup` patch (2026-05-14) bypasses this when resuming
   with identical config.  See diff in glades-trainer/trainer/chiron_main.cpp.

2. **`--bf16-logits-storage` is essential at T=16384.**  Without it, the
   FP32 logits triple (6 GB) plus T-scaled activations OOMs at 18 GB.
   With BF16 storage (3 GB triple) and SCFA skipping sPbf16, T=16384 fits
   at 13.22 GB.

3. **Position-stratified val NLL is the SCFA validator.**  No other
   metric distinguishes "long context works" from "long context is
   nominal."  Add to every long-context run going forward.

4. **NITA at this scale (500 M tokens) is uninformative.**  Saved as a
   capability for later runs (≥5 B tokens) when induction-head circuits
   are expected to be present.
